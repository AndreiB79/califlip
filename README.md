# CaliFlip v7 — Анализатор недвижимости для флипа

Автоматический анализ домов в **Riverside County, California** для флипа.
Вставляешь адрес или ссылку Zillow → получаешь HTML-отчёт с Flip Score и всеми данными.

---

## Что внутри

- `califlip.py` — главный скрипт
- `requirements.txt` — список Python-библиотек
- `where_to_search.html` — отдельная страница со ссылками на сайты для самостоятельного поиска (открывается в браузере без Python)
- `README.md` — эта инструкция

---

## Что получишь на выходе

После запуска откроется HTML-отчёт со следующими данными:

- **Flip Score 0–100** с разбивкой по факторам (год постройки, площадь, история владения, comps, риски)
- **Информация о доме**: APN, год постройки, площадь, спальни, ванные, размер участка
- **Текущий владелец и оценочная стоимость**
- **История продаж** этого дома
- **Comparable sales** — продажи соседних домов в радиусе 0.5 мили за 2 года
- **FEMA flood zone** — риск затопления
- **Что делать дальше** — чеклист для следующих шагов

## Установка (для MacBook, один раз, 5 минут)

### Шаг 1. Проверь что у тебя есть Python 3

Открой Terminal (Cmd+Space → Terminal → Enter) и введи:

```bash
python3 --version
```

Если вышло что-то типа `Python 3.11.5` — у тебя всё есть, переходи к Шагу 2.

Если ошибка "command not found":
- Зайди на https://www.python.org/downloads/
- Скачай последнюю версию Python (большая жёлтая кнопка)
- Запусти .pkg файл, в установщике нажми Continue → Continue → Install
- Закрой Terminal и открой заново
- Снова `python3 --version` — теперь должно работать

### Шаг 2. Скачай эту папку

Положи папку `califlip` куда-нибудь удобно — например, на Рабочий стол.

### Шаг 3. Установи нужные библиотеки

В Terminal перейди в папку проекта и установи зависимости:

```bash
cd ~/Desktop/califlip
pip3 install -r requirements.txt
```

Если выдало ошибку про "externally-managed-environment" (новые macOS), используй:

```bash
pip3 install -r requirements.txt --break-system-packages
```

Должно показать что-то вроде `Successfully installed requests-2.31.0`.

**Готово.** Один раз поставил — больше не нужно.

## Использование

### Способ 1. Анализ по адресу

В Terminal, из папки `califlip`:

```bash
python3 califlip.py "4071 Mission Inn Ave, Riverside, CA 92501"
```

### Способ 2. Анализ по ссылке Zillow

```bash
python3 califlip.py "https://www.zillow.com/homedetails/4071-Mission-Inn-Ave-Riverside-CA-92501/12345_zpid/"
```

Скрипт сам извлечёт адрес из URL, запросит все данные, сгенерирует HTML и откроет его в браузере.

### Где сохраняются отчёты

Все отчёты сохраняются в папку `~/califlip_reports/` (т.е. в твоей домашней директории).
Файлы называются по формату `АДРЕС_ДАТА_ВРЕМЯ.html`.

## Поиск объектов (без Python)

Открой `where_to_search.html` двойным кликом — откроется в браузере.
Там готовые пресет-ссылки на:
- **Zillow** с фильтрами под флип (сниженные цены, fixer-upper, estate sale, pre-foreclosure)
- **Redfin** с фильтрами price drops
- **Realtor.com**
- **Auction.com**, **Hubzu** для foreclosure
- **PropStream**, **BatchLeads** для off-market
- **Riverside County Public Records** (бесплатно)

Плюс:
- Список **ключевых слов** для поиска (зелёные/красные флаги)
- **Правило 70%** для расчёта максимальной цены покупки

## Что НЕ работает в v7 (честные ограничения)

**1. Текущая listing price с Zillow/Redfin.**
Эти сайты блокируют автоматический сбор. Текущую цену объявления тебе придётся посмотреть глазами и держать в голове рядом с отчётом. Анализ comps + оценочная стоимость от ассесора дадут тебе хорошее представление о реальной цене.

**2. Только Riverside County.**
Если введёшь адрес в LA, Orange или San Bernardino — скрипт покажет ошибку. Добавление этих округов — следующий шаг.

**3. Школы и демография.**
В v7 их нет. Добавлю в v7.1 (нужны бесплатные API-ключи GreatSchools и Census).

**4. Photo / описание дома.**
Этих данных нет в публичных county records. Открой оригинальную ссылку Zillow/Redfin отдельной вкладкой.

## Если что-то пошло не так

**"Адрес не найден в Riverside County":**
- Проверь, что адрес именно в Riverside County (а не Riverside в LA County)
- Попробуй формат: `"Street, City, CA ZIP"` — например `"123 Main St, Hemet, CA 92543"`

**"ModuleNotFoundError: No module named 'requests'":**
- Запусти `pip3 install requests --break-system-packages`

**"HTTP 403 / 404 от Riverside API":**
- Возможно, временно недоступен. Подожди 10 минут.
- Или они изменили структуру API — напиши мне, поправлю.

**Скрипт работает, но HTML пустой:**
- Запусти из Terminal и пришли мне весь вывод — посмотрю логи.
